# Foundry & Frame — Residential Remodeling Website Demo

Reusable FireWorks storefront template for residential remodelers and general contractors. The fictional business identity and all location, contact, hours, service, and process content are samples that must be verified for a purchasing client.

## Local use

```bash
npm test
python3 -m http.server 4173 --directory dist
```

The static build is written to `dist/` for Vercel. Forms deliberately perform browser-local validation only. They do not send, retain, upload, schedule, or charge.

## Demo safeguards

- Search indexing is disabled.
- The gallery distinguishes concept imagery from permissioned completed work.
- No licenses, insurance, certifications, reviews, awards, warranties, years in business, or emergency availability are claimed.
- No delivery, storage, calendar, CRM, messaging, payment, or analytics provider is connected.
- A real launch requires client credentials, privacy/consent decisions, and end-to-end integration testing.
