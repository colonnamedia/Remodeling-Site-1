# Image sources and usage

All three photographic assets are original AI-generated concept images created specifically for this FireWorks template. They contain no logos or text and must not be described as completed contractor projects.

| Asset | Purpose | Source |
|---|---|---|
| `assets/remodeling-craftsman-hero.webp` | Desktop/mobile hero | Original ImageGen output: remodeler fitting walnut cabinetry; left-side copy space |
| `assets/storefront-remodeling.jpg` | 1200×630 social/storefront preview | Optimized crop of the original hero |
| `assets/kitchen-concept.webp` | Kitchen service concept | Original ImageGen architectural concept |
| `assets/bath-concept.webp` | Bathroom service concept | Original ImageGen architectural concept |

The project gallery labels the concept images explicitly. Customer implementations should replace or supplement them with permissioned, credited project photography and a documented before/after record.
